# Firmware utilizado: GRBL 0.9j

O protótipo utiliza **GRBL 0.9j** no Arduino Uno, acessado pelo aplicativo via USB/serial e conectado eletricamente à CNC Shield V3 encaixada nos pinos do Uno.

Para conhecer o código-fonte, autores, licença e documentação do firmware de terceiros, acesse o [repositório Grbl](https://github.com/grbl/grbl).

O firmware e seus arquivos de instalação **não foram incorporados a este portfólio público**. A utilização do firmware não implica autoria sobre o projeto Grbl. A configuração e gravação devem sempre seguir a compatibilidade do Arduino e da Shield utilizados.
